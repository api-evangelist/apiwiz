# APIwiz

> APIwiz is a federated API management platform covering the full API lifecycle — design, build, security, governance, observability, and monetization — with a visual API design studio, federated gateway control across multiple cloud gateways (Apigee, Kong, IBM API Connect), eBPF-powered observability, automated compliance monitoring, and an API marketplace with dynamic pricing. Formerly Itorix.
